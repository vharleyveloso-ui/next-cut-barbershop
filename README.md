# Next Cut Barbershop

Create a modern, dark-themed, high-end landing page for "NEXT CUT BARBERSHOP" inspired by the provided reference design layout and typography.



---



### 🎨 DESIGN SYSTEM & STYLING INSTRUCTIONS



1. **Color Palette:**

   - Background: Pure Pitch Black (`#0A0A0A` / `#000000`) with subtle dark grey card backgrounds (`#121212` / `#161616`).

   - Primary Accent: Neon Red / Crimson (`#FF1E36` / `#E50914`) used for main CTA buttons, badge highlights, and price tags.

   - Text Colors: Crisp White (`#FFFFFF`) for main headings, Light Muted Grey (`#A1A1AA`) for subtext and descriptions.

   - Borders: Subtle thin borders (`1px solid #27272A` / `#222222`) around cards and elements.



2. **Typography & Layout:**

   - Bold, uppercase sans-serif typography for main section titles (e.g., "SHARP CUTS. CLEAN LINES. EVERY TIME.", "OUR TEAM", "GALLERY").

   - Sharp corners or slightly rounded modern corners (`rounded-md` or `rounded-lg`).

   - Clean grid alignments with spacious section padding.
